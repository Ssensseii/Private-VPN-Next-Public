# PrivateVPN Next

Отдельный VPN-клиент для Windows 10/11 x64. Устанавливается отдельно от старого
`PrivateVPN.exe`: другой AppId, папка установки, настройки и имя приложения.
Старый клиент и его настройки не заменяются.

## Установка

1. Открой [Releases](https://github.com/Ssensseii/Private-VPN-Next-Public/releases).
2. Скачай `PrivateVPN-Next-Setup.exe` из последнего prerelease.
3. Запусти установщик от имени администратора.
4. Ярлык на рабочем столе отмечен по умолчанию; его можно отключить в установщике.
5. При необходимости установи Microsoft Edge WebView2 Runtime:
   https://developer.microsoft.com/microsoft-edge/webview2/

Перед запуском Next отключи старый VPN-клиент: два TUN-клиента могут конфликтовать
за системные маршруты. Не удаляй старую папку `C:\\PrivateVPN` и старые настройки.

## Интерфейс

- Широкое окно с боковой навигацией и отдельными экранами: главная, подключение, маршрутизация, проверка, журнал, параметры и информация о программе.
- Компактная панель открывается нажатием левой кнопки на значок в системном трее; в контекстном меню трея также доступны компактный и полный режимы.
- Первый запуск показывает мастер ввода параметров прокси.
- Диагностика показывает фактические результаты TCP CONNECT-проверок, без подмены их ICMP ping или локальным подтверждением TUN.
- Журнал можно искать, фильтровать, копировать и очищать; полная запись остаётся в локальном файле журнала.
- Номер версии сборки в окне «О программе» встраивается в Windows EXE на этапе CI.

## Реализованная логика

- Внешний IPv4/IPv6 по умолчанию идёт через выбранный прокси.
- Частные и локальные IP идут напрямую.
- Пользовательские домены и приложения из списков обхода идут напрямую.
- Автоматической российской маршрутизации нет.
- Адрес прокси разрешается до запуска TUN; sing-box и ускоритель используют закреплённый IP. IP и порт самого прокси явно обходят TUN, поэтому соединение ускорителя не зацикливается обратно в туннель.
- Для проксируемых доменов DNS strategy: `ipv4_only`, чтобы не отправлять AAAA-адреса на прокси, который отклоняет IPv6 destinations. Для явно исключённых доменов и приложений используется прямой DNS с `prefer_ipv4`; IPv6 TUN остаётся включённым.
- Удалённый DNS идёт через DoH Cloudflare по TCP/443 через выбранный прокси; DNS для пользовательских исключений использует прямой DNS.
- Задержка измеряется как медиана трёх успешных SOCKS5 CONNECT или HTTP CONNECT до `1.1.1.1:443` через фактически выбранный маршрут. При включённом ускорителе проверяется локальный SOCKS5 relay вместе с upstream-прокси; локальное подтверждение TCP в TUN не считается результатом.
- Статус «VPN подключён» выставляется только после успешных трёх CONNECT-проверок через выбранный маршрут.
- Ускоритель работает с SOCKS5 и HTTP CONNECT через локальный SOCKS5 relay: для SOCKS5 заранее выполняется greeting/authentication, для HTTP заранее открывается TCP к прокси, а при запросе создаётся аутентифицированный CONNECT-туннель. Пул содержит до двух свободных соединений; неиспользуемые соединения закрываются через 20 секунд, активные туннели — после двух минут без передачи данных.
- Kill Switch отсутствует.
- Поддерживаются SOCKS5 и HTTP CONNECT. HTTP работает по TCP; UDP через HTTP-прокси не поддерживается. При включённом ускорении HTTP-трафик передаётся через локальный SOCKS5 relay, который преобразует CONNECT в HTTP CONNECT с Basic-аутентификацией.

## Сборка и исходники

- Актуальный редактируемый исходный код: `source/unpacked/`.
- `source/parts/` хранит исходный архив первоначального импорта; его SHA-256
  проверяется в CI. После импорта изменения исходников ведутся в `source/unpacked/`.
- Windows-сборка генерирует фирменную многоразмерную иконку (16–256 px) из
  `installer/MakeIcon.ps1`, встраивает её в EXE и кладёт `app.ico` рядом с
  программой для трея и ярлыков.
- Установщик создаёт ярлык рабочего стола по умолчанию и ярлык в меню «Пуск».
- sing-box 1.14.4 загружается из официального релиза и проверяется по SHA-256.
- WebView2 Loader скачивается из Microsoft NuGet package с закреплённой версией.

## Проверка

GitHub Actions выполняет Go-тесты, статический анализ, проверку конфигураций sing-box,
сборку Windows x64 и публикацию prerelease. CI не заменяет проверку TUN,
маршрутизации IPv4/IPv6, обхода приложений и поведения Proxy6 на реальной Windows 10.
